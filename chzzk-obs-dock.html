OBS 실행 시 독 서버 자동 시작 & 종료

💡
최초 1회 등록 필수: OBS 상단 메뉴 [도구] ➔ [스크립트]의 [+] 버튼을 눌러 설치된 chzzk_dock_launcher.lua를 등록해 두시면, 이후 OBS 실행 시 독 서버가 자동 시작됩니다.

📖 네이버 쿠키(NID_AUT, NID_SES) 복사 방법
  1. 브라우저(Chrome, Edge, Whale 등)에서 에 접속하여 로그인합니다.
  2. 키보드 F12 (또는 웹페이지 우클릭 ➔ [검사])를 눌러 개발자 도구를 엽니다.
  3. 상단 탭 메뉴에서 [애플리케이션](Application) 또는 [저장공간](Storage) 탭을 클릭합니다. * 창 폭이 좁아 탭이 안 보이면 상단 우측 » 화살표 아이콘을 클릭하세요.
  4. 좌측 트리 메뉴에서 [저장용량] ➔ [쿠키] ➔ https://chzzk.naver.com(또는 naver.com)을 선택합니다.
  5. 우측 표 목록에서 이름이 NID_AUT와 NID_SES인 항목을 찾습니다.
    📸 [참고 1] 개발자 도구 쿠키 확인 화면
    빨간색 번호 순서대로 [1] 애플리케이션 ➔ [2] 저장용량/쿠키 ➔ [3] NID_AUT / NID_SES를 확인합니다.
  6. 각 항목을 클릭한 뒤 하단 Cookie Value 영역에서 값을 전체 드래그하거나 우클릭 ➔ [복사](Ctrl+C)하여 아래 입력란에 각각 붙여넣습니다.
    📸 [참고 2] Cookie Value 값 복사 방법
    하단 Cookie Value 입력창의 긴 문자열을 우클릭하여 [복사]합니다.
🔒 입력된 쿠키는 외부 서버로 일절 전송되지 않으며, 오직 내 컴퓨터의 Windows 자격 증명 관리자(보안 금고)에만 안전하게 암호화 보관됩니다.
