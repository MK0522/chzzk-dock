# v0.6.2-Beta — 설정 UI 탭 분리 및 독 화면 크기·시청자 수 설정 저장 개선

> ⚠️ **주의 (Beta)**: 설정 저장 방식 개편이 포함된 Beta 빌드입니다. 이상 동작 발생 시 시스템 트레이의 **[📋 진단 리포트 클립보드 복사]**를 통해 제보해 주세요.

이번 업데이트는 **설정 창 내 전용 [🎨 UI] 탭 신설**, **독 화면 크기 및 시청자 수 표시 설정의 안전한 영구 보존**, **재시작 시 크기 초기화 결함 수정**, 그리고 **업데이트 알림 건너뛰기 동작 안정화**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 🎨 [화면 설정 UI]

#### 설정 창 내 전용 [🎨 UI] 탭 신설 및 메뉴 정돈
- 설정 메뉴 좌측에 새로운 **`[🎨 UI]`** 탭을 추가하여 화면 모양 및 인터페이스 관련 설정을 한곳에 모아서 제공
- 기존 [⚙️ 일반] 탭에 섞여 있던 '독 화면 크기'와 '시청자 수 표시' 설정을 새 UI 탭으로 분리하여 찾기 쉽게 개편
- 탭 메뉴 버튼 순서와 실제 내용 화면 순서를 일치시켜 설정 조작 동선 개선

#### 앱 정보 탭 안내문 배치 정돈
- 설정 > 앱 정보 탭의 "⚠️ 비공식 API 연동 안내" 문구를 오픈소스 라이선스 아래, 최하단 버전 정보 위쪽으로 이동하여 읽기 편하게 배치

### 💾 [설정 저장 안정성]

#### 독 화면 크기 및 시청자 수 표시 설정 영구 보존
- OBS 독을 껐다 켜거나 캐시를 지워도 내가 선택한 독 화면 크기(100%, 120%, 135%)와 시청자 수 표시 켜기/끄기 설정이 풀리지 않고 안전하게 유지되도록 저장 방식 개선
- 프로그램을 실행할 때와 설정창을 열 때 내가 저장해 둔 크기와 시청자 수 표시 상태를 즉시 화면에 자동 반영

## 🛠️ 수정

### 🔤 [독 화면 크기]

#### 프로그램 재시작 시 독 화면 크기가 120%로 되돌아가던 문제 수정
- 독 화면 크기를 100%(보통) 또는 135%(아주 크게)로 변경했음에도 프로그램을 완전히 종료 후 다시 켜면 기본 크기(120%)로 풀려버리던 결함 수정

### 🔄 [업데이트 알림]

#### 새 버전 알림 속도 및 '이 버전 건너뛰기' 동작 안정화
- 업데이트 팝업에서 [이 버전 건너뛰기]를 누르면 다음 버전이 나오기 전까지 해당 버전 알림이 다시 뜨지 않도록 저장 동작 개선
- 업데이트 확인 시 불필요한 반복 통신을 줄여 알림 반응 속도 향상

## 📦 변경(패치)

### 🧹 [최적화]

#### 구버전 임시 잔류 데이터 전면 정리
- 이전 버전에서 브라우저 임시 저장소에 남아있던 불필요한 호환 코드를 모두 정리하여 프로그램이 더 가볍고 깔끔하게 구동되도록 최적화

### 💾 [설정 및 배포]

#### 기존 설정 및 세션 안전 보존
- 이전 버전에서 사용하시던 네이버 로그인 정보, 방송 프리셋 및 기본 설정값은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 설치형 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-windows-amd64-installer.exe`) 패키지로 제공됩니다.
