# v0.6.2-Beta2 — 네이버 로그인 즉시 종료 핫픽스 및 다중 계정 전환·2차 인증 안정화

> ⚠️ **주의 (Beta)**: 긴급 결함 수정(핫픽스)이 반영된 Beta2 빌드입니다. 이상 동작 발생 시 시스템 트레이의 **[📋 진단 리포트 클립보드 복사]**를 통해 제보해 주세요.

이번 업데이트는 **네이버 로그인 창이 1초 만에 꺼지던 충돌 결함 긴급 해결**, **"이 장치 기억하기"를 통한 2차 인증 건너뛰기 보존**, **다중 계정 전환 시 독 화면 미반영 결함 수정**, 그리고 **로그인 계정(채널명) 명시적 기록 및 중복 로그 정리**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 👥 [다중 계정 및 로그인]

#### 로그인 및 계정 전환 시 스트리머 채널명 명시적 기록
- 네이버 로그인 연동이 완료되거나 다른 계정으로 전환했을 때, 어느 스트리머 계정(채널명 및 채널 ID)으로 연동되었는지 시스템 로그에 명확하게 한 줄로 기록되도록 개선
- 불필요하게 [HTTP]와 [UI Toast]로 중복 출력되던 화면 알림 로그를 정리하여 시스템 기록 가독성 향상

## 🛠️ 수정

### 🔐 [네이버 로그인 웹뷰]

#### 로그인 시작 시 창이 1초 만에 비정상 종료되던 결함 긴급 해결
- 로그인 화면이 열린 직후 내부 브라우저 엔진 자원 정리 충돌로 인해 창이 1초도 안 되어 저절로 꺼지던 크래시 결함 수정
- 네이버 로그인 입력 화면이 화면에 안정적으로 상주하여 사용자 입력을 정상적으로 대기하도록 조치

#### 이전 계정 자동 로그인으로 인한 창 즉시 꺼짐 방지 및 2차 인증 기억 보존
- 이전 계정이 로그인되어 있던 상태에서 새 계정 연동을 시도할 때, 이전 계정으로 자동 로그인되면서 창이 곧바로 닫히던 문제 수정
- 기기 등록 토큰("이 장치 기억하기")은 안전하게 보존하여 2차 인증(OTP)은 건너뛰면서도, 세션 정보만 선별 소멸시켜 항상 정상적인 로그인 입력 화면이 열리도록 개선

### 🔄 [계정 전환]

#### 다른 계정으로 전환 시 독 UI 화면(채널명·아바타·설정)이 바뀌지 않던 결함 수정
- 상단 계정 목록 팝오버에서 부캐/다른 계정으로 전환했음에도 독 상단 채널명과 아바타, 방송 설정이 이전 계정 상태로 멈춰있던 캐시 동기화 결함 수정
- 계정을 여러 번 번갈아 전환할 때 내부 계정 목록 순서가 꼬이거나 전환이 멈추던 배열 처리 오류 수정

## 📦 변경(패치)

### 🧹 [최적화]

#### 브라우저 화면 알림(Toast) 백엔드 전송 배제
- 화면에 잠시 떴다 사라지는 단순 안내 메시지가 백엔드 내부 로그를 어지럽히지 않도록 전송 파이프라인 정리

### 💾 [설정 및 배포]

#### 기존 설정 및 다중 계정 안전 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 설치형 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-windows-amd64-installer.exe`) 패키지로 제공됩니다.
