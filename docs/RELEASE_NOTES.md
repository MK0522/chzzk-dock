# Chzzk-Dock 0.6.3

# 다중 계정·미니 독·원클릭 업데이트 및 프로세스 안정화

이번 업데이트는 **v0.5.12 이후 첫 정식 릴리즈**로, **다중 계정 전환**, **초경량 미니 독 및 방송 통계 독**, **인앱 원클릭 자동 업데이트**, 그리고 **대기 메모리 절감·창 수명주기 안정화**를 중심으로 전면 개편되었습니다.

## 🌟 개선/추가

### ✨ [신규 기능]

#### 다중 계정 전환 지원
- 여러 치지직 계정을 등록해 두고 상단 프로필 클릭만으로 즉시 계정을 전환하는 기능 추가
- 활성 계정 로그아웃 시 열려 있던 채팅·리모컨 창을 정리하고 남은 계정으로 자동 전환

#### 미니 독 및 방송 통계 독 추가
- 채팅 모드, 슬로우 모드, 후원 제어만 빠르게 조작할 수 있는 초경량 미니 독 추가
- 방송·녹화 상태와 저장 공간 여유를 한눈에 확인하는 OBS 방송 통계 독 추가
- 메인·미니 독 창 상단 항상 위 고정(핀) 기능 지원

#### 인앱 원클릭 자동 업데이트
- 프로그램 내에서 새 버전을 확인하고 클릭 한 번으로 다운로드·설치·재실행까지 진행하는 자동 업데이트 도입
- 설치 실행 시 파일 무결성(SHA-256) 검증 및 업데이트 완료 후 화면 자동 새로고침 지원

#### 카테고리 즐겨찾기·스트림 키
- 방송 카테고리 즐겨찾기 및 최근·인기 카테고리 추천 목록 제공
- 독 화면에서 스트림 키 확인 및 재발급 기능 지원

#### 설정 탭 개편 및 진단 리포트
- 설정 화면을 일반·로그인·고급·정보 탭으로 재구성하고 독 크기·글꼴 배율·시청자 수 표시 설정 유지 개선
- 시스템 사양과 최근 실행 로그를 한 번에 저장하는 진단 리포트 기능 추가

### ⚡ [성능/편의성]

#### 유휴 메모리 약 240MB 절감
- 시작 시 독 창을 띄우지 않는 경우 브라우저 엔진을 지연 실행해 초기 대기 메모리 사용량 약 240MB 절감
- 트레이 메뉴에서 독 열기를 선택하는 시점에 창을 즉시 생성하도록 최적화

#### 채팅·리모컨 창 즉시 실행
- 채팅창이나 공식 리모컨을 열 때 불필요한 계정 상태 재조회를 생략해 대기 없이 바로 실행되도록 개선
- OBS 연동 스크립트(Lua)에서 표준 설치 경로를 기본 인식하고, 안내 문구를 직관적으로 간소화

## 🛠️ 수정

### 🛡️ [프로세스 안정성]

#### 창 닫기 시 연쇄 종료 방지
- 채팅창이나 리모컨 창의 [X] 버튼을 닫았을 때 다른 독 창이나 서버가 함께 종료되던 결함 수정
- 인스톨러 실행 중에도 프로그램을 안전하게 종료한 뒤 교체하도록 2단계 종료 절차 적용

#### 트레이 아이콘 누락 및 OBS 연동
- 실행 파일 내부에 아이콘을 직접 내장해 특정 환경에서 트레이 아이콘이 빈칸으로 보이던 현상 수정
- OBS 자동 실행 스크립트 버전 비교 방식을 개선해 동일 버전에서 업데이트 안내가 반복되던 현상 수정
- OBS scripts 폴더를 찾지 못했을 때 잘못된 위치에 스크립트를 생성하지 않도록 경로 검증 보강

### 🎨 [UI/UX 및 기능]

#### 업데이트 자동 새로고침·스크립트
- 업데이트 완료 후 새 버전 서버가 켜지면 대기 중이던 독 화면을 자동으로 새로고침하도록 개선
- 업데이트 실패 시 원인 안내 및 다시 시도 버튼을 표시하고, 미니 독 상태 조회 실패 시 자동 재시도 적용

#### 드롭스·로그인·배율 드래그 수정
- 방송 정보의 드롭스 보상 연동이 정상 반영되지 않던 문제 수정
- 네이버 로그인 창 외부 링크 이동을 제한하고 2차 인증 기기 기억 상태가 유지되도록 개선
- 화면 배율을 변경한 상태에서도 독 창 드래그·크기 조절 및 팝업 위치가 어긋나던 문제 수정

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 정보 보존
- 기존에 연동해 둔 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 창 크기 설정은 업데이트 후에도 그대로 유지됩니다.
- 구버전 임시 캐시와 불필요한 잔여 파일을 정리해 실행 환경을 깔끔하게 유지합니다.

#### 공식 설치형 인스톨러 제공
- 공식 설치형 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 배포되며, 검은 콘솔 창 없이 백그라운드 트레이로 실행됩니다.
