# Chzzk-Dock 0.6.3 RC 3

## 계정 및 창 관리

- 활성 계정에서 로그아웃하면 열려 있던 채팅과 리모컨 창을 닫습니다.
- 저장된 계정이 남아 있으면 다음 계정으로 전환하고 독의 방송 설정을 새로 불러옵니다.
- 채팅, 리모컨, 로그인 창의 부모 프로세스를 확인할 수 없을 때 실패 원인을 독 로그와 진단 파일에 기록합니다.

## 독 화면

- 미니 독에서 상태 조회에 실패하면 자동으로 다시 확인합니다.
- 통계 독에서 저장 공간 조회 상태를 구분해 표시합니다.
- 메인 독 설정 스위치의 접근성과 팝업 창 크기 조절을 개선했습니다.

## 자동 업데이트

- 업데이트 확인에서는 다운로드한 설치 파일을 매번 해시 검사하지 않고, 설치 실행 시 SHA-256으로 무결성을 확인합니다.
