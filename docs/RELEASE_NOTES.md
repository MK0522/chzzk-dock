# v0.6.3-alpha1 — 초경량 미니 독 지원 및 화면 구조 분리·스트림 키 재발급

이번 업데이트는 **OBS 상시 거치용 초경량 미니 독(`/mini`) 신설**, **독 화면 구조 폴더 단위 분리 및 실행 속도 최적화**, **스트림 키 원클릭 재발급 연동**, **썸네일 크롭 영역 전역 드래그 지원**, 그리고 **카테고리 13개 최적화 및 스마트 추천 보장**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 🕹️ [미니 독 및 팝업 제어]

#### OBS 상시 거치용 원클릭 초경량 미니 독(/mini) 탑재
- OBS 상단이나 하단 좁은 여백에 쏙 들어가는 2열 콤팩트 제어 바 형태의 새로운 미니 독 지원
- 1열에서 채팅창 열기, 이모티콘 전용 채팅, 저속 모드를 즉시 켜고 끌 수 있으며, 2열에서 후원 4종(채팅, 영상, 미션, 구독 알림)을 원클릭으로 손쉽게 제어 가능
- 기존 메인 방송 독과 설정을 완벽하게 공유하며 각 버튼마다 독립적인 백엔드 통신을 수행하도록 최적화

#### 독 팝업창 전용 플로팅 고정 핀 및 화면 배율 드래그 보정
- 방송 독 팝업창을 항상 다른 창보다 위에 띄워둘 수 있는 편리한 고정 핀 버튼 제공
- 독 화면 크기(100%, 120%, 135%)를 변경해도 핀 버튼 이동 좌표가 어긋나지 않고 마우스에 정확하게 밀착되도록 보정

### 🔑 [방송 설정 및 관리]

#### 치지직 스트림 키 원클릭 재발급 지원
- 방송 URL 설정 패널에서 치지직 공식 안내 대화상자를 거쳐 스트림 키를 한 번의 클릭으로 안전하게 재발급받을 수 있도록 연동
- 방송 독 URL 목록을 [OBS 독] 그룹으로 정돈하고, 메인 독(`/`), 미니 독(`/mini`), 방송 통계 독(`/stats`) 주소를 간편하게 복사할 수 있도록 지원

#### 채팅 권한 변경 즉시 반영(Auto-apply) 전환
- 채팅 참여 권한(전체/팔로워/구독자/운영자), 최소 팔로우 시간, 구독자 예외 설정을 변경하는 즉시 치지직 방송에 실시간으로 자동 적용되도록 개선
- 하단 [적용] 버튼을 따로 누르지 않아도 채팅 권한이 즉시 반영되어 방송 중 빠른 대처 가능

#### 인기 카테고리 추천 풀 5개 보장 및 조회 최적화
- 즐겨찾기에 등록된 게임과 중복되지 않도록 상위 13개만 선별 조회하여 통신량을 대폭 절감하고 항상 5개의 추천 카테고리를 안정적으로 유지
- 드롭스 활성화 카테고리 선택 시 이벤트 보상 아이템 정보와 달성 필요 시간을 정확하게 안내

## 🛠️ 수정

### 🖼️ [썸네일 관리 및 화면 알림]

#### 썸네일 크롭 화면 전역 드래그 및 줌 편의성 개선
- 초록색 사각형 바깥쪽 어두운 여백을 포함한 미리보기 영역 전체 어디를 잡아끌어도 이미지가 부드럽게 이동하도록 개선
- 스테이지 전체에서 마우스 휠 줌인/줌아웃이 자연스럽게 작동하며, 자유 비율 모드의 8방향 크기 조절 핸들도 안정적으로 유지

#### 화면 알림(토스트) 최상단 노출 및 자동 제거
- 썸네일 크롭 창이나 설정 창 등 모달 대화상자가 열린 상태에서도 알림 토스트가 모달 뒤에 가려지지 않고 항상 화면 최상단에 뜨도록 개선
- 알림 표시 3초 후 부드럽게 페이드아웃되며 완전히 사라지도록 소멸 동작 보장

### ⚡ [검색 및 반응성]

#### 카테고리 검색창 닫기 및 중복 검증 지연 개선
- 카테고리 검색 중 바깥 빈 공간을 클릭했을 때 드롭다운 목록이 지체 없이 즉각 닫히도록 반응성 개선
- 키보드 이동 및 마우스 클릭 시 동일한 검증이 이중으로 반복 실행되던 현상을 정리하여 검색 동작 최적화

#### 불필요한 키보드 가로챔 및 클릭 간섭 방지
- 일부 입력창에서 의도치 않게 작동하던 ESC 키 간섭과 방송 설정 카드 전체에 걸려 있던 클릭 가로챔 코드를 정리하여 텍스트 선택 및 마우스 조작감 향상
- 브라우저 콘솔에서 발생하던 불필요한 아이콘 404 요청을 제거하여 내부 통신 정돈

## 📦 변경(패치)

### 🚀 [성능 및 아키텍처]

#### 독 UI 화면 구조 폴더 단위 분리 및 공통 API 클라이언트 단일화
- 각 독 화면 리소스를 `ui/main-dock/`, `ui/mini-dock/`, `ui/stats-dock/`, `ui/shared/`로 체계적으로 분리
- `ui/shared/api.js` 공통 클라이언트를 신설하여 중복 통신 코드를 제거하고, 각 버튼 조작 시 개별 엔드포인트로 경량 요청을 전송하도록 구조 개선
- 과거 레거시 `.html` 주소들을 정리하고 루트(`/`), `/mini`, `/stats` 깔끔한 단축 주소 체계로 일원화

#### 소프트웨어 업데이트 확인 단일화
- 프로그램 시작 시 설정을 점검하고 새 버전을 확인하는 통신 과정을 백엔드 단일 확인 방식으로 압축하여 네트워크 왕복 시간 단축

### 💾 [설정 및 배포]

#### 기존 설정 및 다중 계정 안전 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 설치형 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-windows-amd64-installer.exe`) 패키지로 제공됩니다.
