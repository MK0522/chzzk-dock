# Chzzk-Dock 0.6.3 Beta 2

# v0.6.3-beta2 — OBS 종료 연동 정상화 및 프리 릴리즈 업데이트 감지 수정

이번 업데이트는 **OBS 종료 시 치지직 독이 함께 꺼지지 않던 프로세스 대기 현상 해결**, **사전 릴리즈(베타) 채널에서 새 업데이트가 감지되지 않던 버전 비교 오류 수정**, 그리고 **트레이 설정 변경 시 이전 알림이 반복해서 다시 뜨던 시스템 팝업 오류 수정**에 초점을 맞추었습니다.

## 🌟 개선/추가

### ⏱️ [OBS 연동 편의성]

#### 불필요한 시스템 알림 팝업 정리
- 트레이 메뉴에서 'OBS와 함께 종료' 대기 시간이나 시작 옵션을 바꿀 때마다 화면 우측 하단에 번쩍이며 뜨던 윈도우 시스템 알림 제거
- 메뉴 항목의 체크(V) 마크와 마우스 호버 설명으로만 조용하게 상태가 반영되도록 사용성 개선

## 🛠️ 수정

### 🔄 [자동 업데이트]

#### 프리 릴리즈 업데이트 감지 수정
- 설정에서 '사전 릴리즈(프리 릴리즈) 업데이트 포함'을 켜두었음에도 새로운 베타 버전이 출시되었을 때 최신 버전으로 인식하지 못하고 업데이트 알림이 뜨지 않던 버전 비교 오류 해결
- 테스트용 사전 릴리즈 버전(beta, rc 등) 간의 단계 및 번호를 표준 규격에 맞게 정밀 판별하도록 개선하여 새 베타 버전 자동 감지 정상화

### 🛡️ [프로세스 및 종료 감지]

#### OBS 종료 시 함께 종료 안정화
- OBS Studio 창을 닫았을 때 프로그램이 종료를 감지하지 못하고 백그라운드에 남아있던 현상 개선
- OBS 런처 스크립트의 프로세스 구동 방식을 부모-자식 핸들이 분리된 독립 실행 구조로 전환하여, OBS 창을 닫으면 백그라운드 지연 없이 즉시 완전히 종료되고 독 서버도 함께 자동 종료되도록 보정

### 🔔 [트레이 및 시스템 알림]

#### 트레이 메뉴 알림 중복 팝업 수정
- 트레이나 설정 화면에서 설정을 변경할 때 처음에 떴던 '서버가 시작되었습니다' 알림이 화면에 계속 다시 나타나던 윈도우 시스템 알림 오류 해결
- 마우스 호버 안내 문구만 깔끔하게 갱신되도록 윈도우 알림 제어 방식을 분리하여 중복 팝업 방지

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 안전 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-windows-amd64-installer.exe`) 패키지로 제공됩니다.
