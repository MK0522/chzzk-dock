# Chzzk-Dock 0.7.0 Alpha 1

# 투명 채팅 오버레이 및 멀티 소스 레이어 추가

이번 업데이트는 **게임·전체 화면 위에 띄우는 투명 채팅 오버레이**와 **여러 알림·위젯 소스를 함께 관리하는 레이어 기능**을 첫 알파 프리릴리즈로 선보이는 데 초점을 맞추었습니다.

## 🌟 개선/추가

### ✨ [오버레이]

#### 투명 채팅·멀티 소스 창
- 기본 치지직 채팅창은 물론 외부 후원·알림 위젯 주소까지 여러 개의 투명 오버레이 소스를 추가해 동시에 화면에 띄울 수 있도록 지원
- 방송 소스 → 오버레이 설정 탭과 시스템 트레이의 `오버레이 레이어 관리`에서 각 소스의 표시/숨김, 드래그·버튼을 통한 겹침 순서 조정, 로그인 연동 여부 및 사용자 CSS 적용 제공
- 프로그램 재실행 시 이전에 켜 두었던 오버레이 소스와 연결된 모니터 위치를 자동으로 복원

#### 3단계 모드·전역 단축키
- `수정`(위치·크기 편집) ↔ `상호작용`(클릭 가능) ↔ `고정`(마우스 클릭 통과) 3가지 모드를 자유롭게 전환해 게임이나 전체 화면 작업 중에도 방해 없이 채팅 확인 가능
- 독 환경 설정 → `단축키` 탭에서 최대 4개 키 조합의 전역 단축키를 지정·해제하여 창을 벗어나지 않고 즉시 오버레이 모드를 순환 전환

#### 창 크기·영역 자르기 조절
- `수정` 모드에서 창 테두리·모서리 드래그로 8방향 크기 조절, `Alt + 드래그`로 원하는 화면 영역만 잘라내기, `Esc` 키로 조절 즉시 취소 지원

#### 투명도·배경 실시간 미리보기
- 창 전체 불투명도, 배경 불투명도, 배경 색상, 후원 메시지 배경 불투명도를 소스 설정 슬라이더로 조절할 때 켜져 있는 오버레이에 즉시 실시간 반영
- 저장하지 않고 창을 닫거나 취소하면 조절 전 원래 모양으로 자동 복원

#### 깔끔한 채팅 화면 정리
- 기본 치지직 채팅 오버레이에서는 상단 고정 메시지, 안내 배너, 채팅 입력창과 스크롤바를 숨겨 방송 화면 위에 채팅 본문만 깔끔하게 표시

## 🛠️ 수정

### 🎨 [UI/UX]

#### 크기 조절 시 흰 배경 수정
- 투명 오버레이 창의 테두리를 드래그해 크기를 조절할 때 창 전환 과정에서 배경이 흰색으로 깜박이거나 덮이던 현상 수정

#### 미로그인·단축키 접근 개선
- 치지직 계정 로그인 전에도 상단 방송 소스 버튼을 열어 `오버레이 설정` 탭과 단축키 기능을 바로 사용할 수 있도록 진입 제한 완화
- 방송 소스 패널을 `스튜디오 URL`과 `오버레이 설정` 두 개의 탭으로 구분해 관리 동선 정리

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 알파 트랙·리모컨 검증 안내
- `v0.7.0-alpha1`은 투명 오버레이 초기 검증용 프리릴리즈로 우선 제공되며, 일부 리모컨 기능(실서버 후원·파티 피드 확인) 검증 작업과 병행 진행
- 정식 안정판은 기존 `v0.6.4` 기준으로 유지

#### 기존 설정 및 계정 유지
- 기존에 저장된 네이버 로그인 계정, 방송 프리셋, 리모컨 필터 색상, 창 크기 및 테마 설정은 업데이트 후에도 유지

#### 공식 설치형 인스톨러 제공
- 공식 설치형 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공
