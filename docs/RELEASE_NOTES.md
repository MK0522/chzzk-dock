# Chzzk-Dock 0.6.5 Alpha 2

# 라이트 테마·실시간 테마 동기화 및 방송 통계·리모컨 개선

이번 업데이트는 **다크·라이트 테마 실시간 동기화**, **방송 통계 독의 목표 FPS/비트레이트 색상 및 개별 보기 기능**, **리모컨 필터 색상 가독성 보정**, 그리고 **설정 유실·창 조작성·오프라인 호환성 개선**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 🎨 [테마/시각]

#### 라이트·다크 테마 실시간 연동
- 메인 독에서 화면 테마를 전환하면 미니 독, 통계 독, 독립 팝업 창까지 즉시 같은 테마로 바뀌도록 개선
- 라이트 테마에서 배경과 비슷해 잘 보이지 않던 앱 정보 제목, 디스크 잔여 용량 바, 버튼·입력창 글자 대비를 선명하게 보정
- 독 환경 설정 좌측 탭 사이에 구분선을 추가하여 항목 구분감 향상

#### 리모컨 필터 글자색 자동 보정
- 리모컨 필터 칩 색상을 자유롭게 지정해도 다크/라이트 테마 배경에서 글자가 묻히지 않도록 밝기 대비를 자동 보정
- 테마를 바꿀 때도 지정한 필터 칩·피드 카드 글자색이 현재 배경에 맞게 즉시 재조정

#### 통계 독 FPS·비트레이트 색상
- OBS에 설정된 목표 FPS와 출력 비트레이트를 자동으로 불러와 실제 수치를 빨강(0%)·노랑(50%)·초록(100%) 연속 색상으로 표시
- CQP 같은 가변 화질 녹화 모드에서는 비트레이트 경고 색상을 끄고 기본 데이터 색상과 통일
- 상단 아이콘과 `통계 (Stats)` 제목을 하나의 박스로 묶고 저장 용량 뱃지와 게이지 바 색상을 더 밝게 조정

### ⏱️ [편의성]

#### 통계 독 방송·녹화 개별 보기
- 기존의 단일 접기/펼치기 방식 대신 `방송`과 `녹화` 활성화 버튼을 각각 분리하여 원하는 항목만 선택적으로 표시

#### 채널 선택 시 팔로워 수 표시
- 상단 프로필 클릭으로 채널 선택 메뉴를 열면 각 계정의 팔로워 수를 함께 표시하고, 열어둔 동안 10초마다 자동 갱신

## 🛠️ 수정

### 🛡️ [안정성]

#### 후원·구독 알림 설정 유실 수정
- 후원 상세 설정·전광판·썸네일·프리셋 창을 열 때 치지직 최신 설정을 즉시 다시 조회해 화면에 반영하도록 수정
- 채팅 후원 조건이나 구독 알림 볼륨처럼 일부 항목만 저장할 때도 나머지 기존 설정값이 초기화되지 않고 그대로 유지되도록 개선
- 통계 독 OBS 연결이 끊기면 최대 3회 재연결을 시도한 뒤 끊김 상태로 전환하며, 기존 마지막 통계 수치는 유지

### 🖱️ [UI/UX]

#### Esc 닫기 및 우클릭 복사 개선
- 모든 모달, 팝오버, 드롭다운, 설정·URL·리모컨 패널에서 `Esc` 키를 누르면 맨 위 창부터 차례대로 닫히도록 통일
- 빈 공간 우클릭 시 브라우저 기본 메뉴가 뜨는 불편을 막고, 입력창이나 드래그로 선택한 글자 위에서는 복사·붙여넣기 메뉴를 그대로 허용

#### 미니 독 스위치·연결 테두리 보완
- 미니 독의 토글 스위치와 저속 모드 선택 상자를 메인 독과 같은 디자인으로 통일해 라이트 테마 시인성 개선
- 미니 독 하단 연결 상태 글자와 테두리 선이 서로 겹치지 않도록 분리

#### 플로팅 핀 기본 위치·썸네일 창
- 독립 창 플로팅 핀의 기본 위치를 우측 하단으로 변경
- 글자 크기·창 크기 조절 시 UI 비율과 여백을 보완하고 썸네일 관리 창의 `Esc` 닫기 및 잘림 현상 수정

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 오프라인·네트워크 환경 UI 호환
- 외부 웹 스타일 다운로드에 의존하지 않고 프로그램 내부에 정적 스타일 파일을 함께 내장해 네트워크 차단·방화벽 환경에서도 동일한 화면 유지

#### 기존 설정 및 계정 유지
- 기존에 저장된 네이버 로그인 계정, 방송 프리셋, 리모컨 필터 색상, 창 크기 및 테마 설정은 업데이트 후에도 유지됩니다.

#### 공식 설치형 인스톨러 제공
- 공식 설치형 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공됩니다.
