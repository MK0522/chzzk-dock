# Chzzk-Dock 0.7.1 RC 2

# OBS 33 스크립트 대응 및 보안·편의성 개선

이번 업데이트는 **OBS Studio 33 버전 스크립트 경로 자동 대응**, **내부 보안·동시성 안정화**, 그리고 **방송·통계·오버레이 사용 중 확인된 불편 사항 개선**에 초점을 맞추었습니다.

## 🌟 개선/추가

### ⏱️ [편의성]

#### OBS 33 경로 자동 판별
- 설치된 OBS 실행 파일 버전을 직접 확인해 OBS 33 이상(`core\frontend-tools\data\scripts`)과 32 이하(`data\obs-plugins\frontend-tools\scripts`)에 맞는 폴더로 런처 스크립트를 자동 설치
- OBS 32 이하에서 33 이상으로 업데이트한 환경이 감지되면 변경된 경로와 `[+]` 재등록 안내 팝업 및 적용 방법 문구를 함께 표시
- 이미 같은 최신 스크립트가 설치된 경로에 다시 설치하거나 폴더를 선택할 때 실수를 막기 위한 재설치 확인 창 추가

#### 오버레이 우클릭·폴더 열기 개선
- 투명 오버레이 창에서 우클릭 메뉴를 허용해 텍스트 복사 등 기본 브라우저 동작을 바로 사용할 수 있도록 개선
- 통계 독에서 `녹화 폴더 열기`를 누를 때마다 현재 OBS에 설정된 최신 저장 경로를 즉시 확인해 열도록 개선

## 🛠️ 수정

### 🛡️ [보안/안정성]

#### 로컬 통신·동시성·로그 보호
- 로컬 API 요청과 WebView2 브리지 메시지의 허용 출처 검증 및 민감한 토큰·인증 정보 로그 마스킹 보강
- 네이버·치지직 세션 만료 판별 기준을 명확한 인증 오류 응답 기준으로 정리해 일시적인 네트워크 오류로 계정이 만료 처리되지 않도록 개선
- 설정 저장, 프로세스 종료, 오버레이·프로필 처리 구간의 동시성 경합과 메모리 정리 보완

### 🎨 [UI/UX]

#### 카테고리 이미지·화면 표시 수정
- 프로토콜이 생략된(`//...`) 일부 카테고리(예: 리그 오브 레전드) 포스터 이미지 주소를 `https:`로 보정해 목록과 즐겨찾기에서 정상 표시
- 미니 독 상태 표시, 프리셋·설정 화면 배치, 창 크기 변경 표시 등 UI 세부 동작 다듬기

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 유지
- 기존에 저장된 네이버 로그인 계정, 방송 프리셋, 즐겨찾기, 리모컨 필터 색상, 창 위치·테마 설정은 업데이트 후에도 유지

#### 공식 설치형 인스톨러 제공
- 공식 설치형 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공
