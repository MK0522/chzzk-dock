# Chzzk-Dock 0.6.3 RC 1

# 프로세스 수명주기 안정화 및 인스톨러 업데이트 완결

이번 업데이트는 **창 닫기 시 화면 꺼짐 및 자식 창 누수 방지**, **유휴 메모리 지연 초기화(~240MB 절감)**, **인스톨러 정상 종료 신호 우선 안내**, 그리고 **채팅/리모컨 창 즉시 실행 캐시 최적화**에 초점을 맞추었습니다.

## 🌟 개선/추가

### ⚡ [성능/최적화]

#### 유휴 메모리 절감
- 시작 시 독 팝업창을 띄우지 않는 경우 웹뷰 브라우저 엔진을 지연 초기화하여 초기 메모리 사용량 약 240MB 절감
- 트레이 메뉴에서 독 열기를 클릭하는 시점에 즉시 안전하게 창을 로드하도록 개선

#### 채팅·리모컨 즉시 실행
- 독 화면에서 채팅창 또는 공식 리모컨을 열 때 발생하던 불필요한 네이버 서버 재조회 제거
- 백엔드 활성 채널 캐시를 활용하여 버튼 클릭 시 대기 시간 없이 즉시 팝업창이 뜨도록 최적화

### ⏱️ [설치 및 편의성]

#### 인스톨러 종료 안내 개선
- 프로그램 실행 중에 설치기를 실행했을 때 무조건 강제 종료하던 방식을 개선하여 정상 종료 신호 우선 전송
- 1차 안내에서 트레이 종료를 권장하고, 2차 설치 진행 시 프로그램을 안전하게 정리 후 닫도록 2단계 안전장치 적용

#### OBS 런처 경로 설정 개선
- OBS 연동 스크립트(Lua)에서 표준 설치 경로를 기본값으로 자동 인식하도록 개선
- 커스텀 설치 경로를 사용하는 경우에만 경로 입력창이 노출되도록 설정 화면 단순화

## 🛠️ 수정

### 🛡️ [프로세스 안정성]

#### 창 닫기 시 화면 꺼짐 방지
- 채팅창이나 공식 리모컨 창의 [X] 버튼을 눌러 닫았을 때 다른 독 창 화면까지 꺼져버리던 결함 수정
- 윈도우 커널 작업 개체 분리를 통해 메인 서버 프로세스 종료 시에만 자식 창들이 안전하게 일괄 회수되도록 격리

#### 트레이 아이콘 표시 정상화
- 특정 윈도우 환경 및 OBS 연동 실행 시 시스템 트레이에 프로그램 아이콘이 보이지 않던 결함 수정
- 실행 파일 내부에 아이콘 데이터를 직접 내장하고 다중 복원 경로를 적용하여 항상 선명하게 표시되도록 보강

#### 웹뷰 오류 시 강제종료 방지
- 웹뷰 초기화 도중 일시적 오류 발생 시 백그라운드 서버까지 함께 종료되던 결함 수정
- 오류 발생 시 트레이 알림으로 상황을 알리고 백그라운드 서버는 안정적으로 상주하도록 개선

## 📦 변경(패치)

### 🔄 [자동 업데이트]

#### 인앱 자동 재실행 복구
- 프로그램 내에서 자동 업데이트 완료 후 새 버전이 자동으로 즉시 다시 실행되도록 실행 플래그 복구

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공
