# Chzzk-Dock 0.6.3 Beta 1

# v0.6.3-beta1 — 플로팅 핀 배율 드래그 및 인기 카테고리 안정화

이번 업데이트는 **독 화면 크기 조절 시 플로팅 고정 핀 버튼이 옆으로 밀려나던 현상 수정** 및 **인기 카테고리 로드 실패 오류 해결**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 📌 [조작 편의성]

#### 플로팅 핀 커서 추적 개선
- 독 화면 배율(100%, 120%, 135%) 설정과 상관없이 마우스 드래그 시 핀 버튼이 커서 위치를 자연스럽고 정확하게 따라오도록 개선
- 버튼을 끌어서 놓았을 때의 마지막 위치 기억 및 창 상단 배치 편의성 향상

## 🛠️ 수정

### 🔤 [화면 배율 및 조작]

#### 배율 변경 시 핀 좌표 어긋남 수정
- 독 화면 크기를 120% 또는 135%로 확대한 상태에서 핀 버튼을 드래그할 때 버튼이 마우스 왼쪽으로 튕기거나 밀려나던 위치 계산 오류 수정
- 화면 배율의 영향을 받지 않는 독립 영역 좌표계를 적용하여 부드럽고 안정적인 드래그 이동 보장

### 📋 [방송 카테고리]

#### 인기 카테고리 로드 실패 수정
- 방송 설정 카드에서 실시간 인기 카테고리를 불러올 때 간헐적으로 발생하던 로드 실패 및 빈 목록 오류 해결
- 추천 카테고리 데이터가 화면에 정상적으로 즉시 표시되도록 내부 통신 응답 보완

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 안전 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-windows-amd64-installer.exe`) 패키지로 제공됩니다.
