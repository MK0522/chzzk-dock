# Chzzk-Dock 0.7.0 RC 1

# 투명 채팅 오버레이 고도화 및 방송 설정 정돈

이번 업데이트는 **투명 채팅 오버레이의 상호작용·랭킹·스타일 제어 고도화**와 **방송 정보·후원·단축키·소스 설정 화면 정돈**에 초점을 맞추었습니다.

## 🌟 개선/추가

### ✨ [오버레이]

#### 모드별 사용자 스타일 분리
- 소스 설정의 사용자 스타일 입력란을 `수정` / `상호작용` / `고정` 3개 탭으로 분리해 모드마다 다른 디자인 적용 가능
- 각 탭별 용도 설명과 입력 예시를 함께 제공

#### 채팅 글자 크기 설정 추가
- 소스 설정의 `크기 · 배경 설정`에서 채팅 글자 크기를 `100%~170%` 범위로 조절하고 실시간 미리보기 지원
- 오버레이 하단의 배율 조절 버튼을 제거해 입력줄 공간 확보

#### 상호작용 모드 상단 정리
- 상호작용 모드 상단의 `채팅` 제목 줄을 없애고 `⋮` 더보기 메뉴 버튼을 하단 `채팅` 버튼 왼쪽으로 이동
- 드롭스 진행 안내, 환영 문구, 필터링 안내 배너를 모든 모드에서 숨김 처리

#### 랭킹 자동 숨김·렉 완화
- 후원 랭킹이 비어 있을 때는 랭킹 줄을 자동으로 숨기고, 랭킹이 생기면 즉시 한 줄 흐름 표시로 복구
- 랭킹을 클릭해 펼칠 때 채팅 목록이 흔들리거나 느려지던 현상 완화

### ⏱️ [편의성]

#### 카테고리 드롭스·접기 지원
- 카테고리 목록에 `드롭스 진행 중` 섹션을 추가하고 `즐겨찾기` / `추천` / `드롭스` 섹션별 접기·펼치기 상태 저장
- 즐겨찾기 추가·해제 시 확인 창을 거쳐 실수 방지

#### 베타 기능 다시 보지 않음
- `수익 요약`과 `리모컨` 베타 안내 창에 `다시 보지 않음` 체크 옵션을 추가해 OBS 독과 별도 창 모두에서 설정 유지

#### 소스 목록 1열·2열 전환
- 방송 소스 → 오버레이 설정 상단에 `1열` / `2열` 배치 전환 버튼 추가
- 소스 추가와 수정 창을 중앙 창으로 통일하고, 빈 배경 클릭 시 닫히도록 개선하며 삭제 전 확인 창 추가

## 🛠️ 수정

### 🛡️ [오버레이/안정성]

#### 오버레이 모드·위치 유실 수정
- `상호작용` 모드 상태에서 창을 열었을 때 간혹 `고정` 모드로 열리던 현상 수정
- 창을 옮기거나 크기·자르기를 마친 즉시 위치와 크기를 저장해 재실행 후에도 그대로 복원
- 방송·수정·상호작용 모든 모드에서 오버레이 창이 `Alt+Tab` 목록에 뜨지 않도록 개선
- 소스 주소나 이름을 바꿀 때 켜져 있던 오버레이가 꺼지지 않고 자동 재시작되도록 수정
- 채팅 목록을 위로 스크롤할 때 상단 랭킹 줄이 잘리던 현상 수정

### 🎨 [UI/UX]

#### 방송·후원·파티 동선 수정
- 카테고리 목록을 연 상태에서 창 밖을 클릭했다 돌아와도 목록이 닫히거나 초기화되지 않도록 개선
- `파티 후원` 팝업에서 하위 화면을 보다가 닫은 뒤 다시 열면 첫 화면으로 초기화되도록 수정
- 단축키 설정 화면에 입력 방법과 주의사항 안내를 추가하고, 후원 팝업 색상을 기본 화면 톤과 통일

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 유지
- 기존에 저장된 네이버 로그인 계정, 방송 프리셋, 즐겨찾기, 리모컨 필터 색상, 창 위치·테마 설정은 업데이트 후에도 유지

#### 공식 설치형 인스톨러 제공
- 공식 설치형 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공
