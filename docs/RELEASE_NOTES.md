# v0.6.1-Beta — 다중 계정 전환 및 카테고리 즐겨찾기

> ⚠️ **주의 (Beta)**: 다중 계정 세션 마이그레이션이 포함된 Beta 빌드입니다. 이상 동작 발생 시 시스템 트레이의 **[📋 진단 리포트 클립보드 복사]**를 통해 제보해 주세요.

이번 업데이트는 Windows 자격 증명 관리자 기반 **다중 계정(부캐) 세션 전환**, **카테고리 즐겨찾기 및 실시간 인기 카테고리 스마트 추천**, **4분할 퀵 액션 플로팅 팝오버 개편**, 그리고 **자동 업데이트 제어 및 UI 디테일 폴리싱**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 👥 [다중 계정]

#### 다중 계정(부캐) 세션 원클릭 전환 및 병렬 상태 조회
- Windows 자격 증명 관리자(Credential Manager)에 다중 계정 세션을 안전하게 보관하도록 마이그레이션 적용
- 계정 전환 팝오버에서 등록된 모든 계정의 라이브 진행 여부, 닉네임, 프로필 아바타를 실시간 병렬 조회
- 원클릭으로 본캐/부캐 세션을 즉시 전환하거나 불필요한 계정을 안전하게 삭제할 수 있는 관리 UI 제공

### 🔖 [카테고리 & 검색]

#### 카테고리 즐겨찾기 및 실시간 인기 카테고리 스마트 추천
- 자주 방송하는 카테고리를 즐겨찾기로 등록하여 검색창 포커스 시 즉시 선택할 수 있도록 상단 고정 지원
- 검색창이 비어있을 때 치지직 실시간 라이브 상위 인기 카테고리 5개를 자동 추천 드롭다운으로 표시
- 치지직 공개 API 호출 시 브라우저 식별 헤더를 동봉하여 비정상 차단 예방

### 🎨 [UI & 팝오버]

#### 상단 헤더 36px(h-9) 규격 정렬 및 시인성 개선
- 프로필 아바타(36px)와 채널명 칩(h-9) 크기를 확대하여 스트리머 계정 식별 시인성 대폭 강화
- [🔗 방송 URL] 및 [⚙️ 설정] 버튼의 높이를 36px로 통일하여 헤더 수평 정렬 완성
- 방송 상태 확인 쿨타임(3초) 중 불필요한 중복 토스트 알림을 억제하여 화면 방해 최소화

#### 4분할 퀵 액션 바 및 실시간 플로팅 팝오버 전환
- 퀵 액션 바를 [💬 채팅창], [🛡️ 채팅모드], [🪙 후원], [📱 리모컨] 4개 영역으로 명확히 분리
- 화면 전체를 가리던 슬라이드 패널 대신 버튼 하단에 뜨는 가벼운 플로팅 팝오버로 개편
- 채팅 모드 제어(이모티콘 전용, 슬로우 모드)와 후원 제어/수익 요약을 팝오버에서 원클릭으로 신속히 조작 가능
- 팝오버 외부 클릭 및 ESC 키 입력 시 부드럽게 자동 닫힘 지원

#### 계정 전환 목록 깜빡임 방지 (SWR 캐시)
- 계정 전환 메뉴를 열었을 때 로딩 문구로 화면이 번쩍거리지 않도록 기존 캐시 데이터를 즉시 렌더링 후 백그라운드 갱신

### 🔄 [업데이트 & 설정]

#### 업데이트 자동 확인(AutoCheckUpdate) On/Off 옵션 탑재
- 설정 > 앱 정보 탭에서 시작 시 업데이트 자동 확인을 켜고 끌 수 있는 토글 옵션 신설
- 자동 확인이 꺼진 상태에서도 사용자가 원할 때 수동으로 [업데이트 확인] 버튼을 눌러 점검 가능

#### 정식/테스트(Beta) 릴리즈 분리 화이트리스트 적용
- 릴리즈 태그에 `-beta` 등의 접미사가 포함된 경우 테스트 버전으로 안전하게 판별
- 안정 버전 사용자에게 테스트 버전이 의도치 않게 자동 배포되는 현상 방지

## 🛠️ 수정

### 🖼️ [썸네일 & 크롭]

#### 자유 비율 크롭 시 원본 종횡비 유지
- 자유 비율 크롭 모드 진입 시 이미지 원본 종횡비(Natural Aspect Ratio)를 기준으로 작업 영역을 초기화하여 미리보기 이미지가 찌그러지거나 작아지는 현상 수정

### 🔍 [검색 UI]

#### 카테고리 검색창 브라우저 자동완성 덮임 현상 방지
- 카테고리 검색 인풋에 브라우저 기본 자동완성 기능이 간섭하여 추천 목록을 가리던 현상 비활성화 처리

### 🔗 [방송 URL]

#### 방송 URL 팝오버 내 불필요한 버튼 정리
- 브라우저 독 URL 복사 전용 팝오버에서 용도에 맞지 않는 불필요한 '열기' 버튼 제거

### 🖥️ [시스템 콘솔]

#### 백그라운드 콘솔(도스 창) 잔류 방지
- Windows GUI 서브시스템 빌드 플래그(-H windowsgui)를 정식 적용하여 프로그램 실행 시 콘솔 창이 깜빡이거나 잔류하지 않도록 개선
