# Chzzk-Dock 0.6.3 Beta 3

# 인스톨러 업데이트 시 자동 종료 정상화

이번 업데이트는 **인스톨러로 업데이트할 때 구버전 프로그램이 자동으로 닫히지 않던 현상 해결** 및 **프로그램 종료 처리 일원화**에 초점을 맞춘 긴급 핫픽스입니다.

## 🛠️ 수정

### 🛡️ [프로세스 및 인스톨러]

#### 인스톨러 종료 신호 수신 수정
- 인스톨러로 새 버전을 설치할 때 구버전 프로그램이 닫히지 않고 "모든 응용 프로그램을 자동으로 닫지 못했습니다" 오류 안내창이 뜨던 문제 해결
- 윈도우 및 인스톨러의 종료 요청 신호를 트레이에서 정상 수신하여 설치 전 백엔드 프로세스까지 안전하게 자동 종료되도록 보정

#### 프로세스 종료 흐름 일원화
- 트레이 메뉴 종료, 워치독 자동 종료, 인스톨러 종료 신호 등 모든 종료 경로를 단일 규격으로 통합
- 중복 자원 해제 및 프로세스 잔류 현상을 예방하고 깔끔하게 정상 종료되도록 구조 정리

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 안전 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-windows-amd64-installer.exe`) 패키지로 제공됩니다.
