# Chzzk-Dock 0.6.3 Beta 4

# OBS 실행 안정화 및 드롭스 보상 연동 정상화

이번 업데이트는 **OBS Studio 실행 시 메인 창이 간헐적으로 켜지지 않던 백그라운드 멈춤 현상 해결**, **OBS 연동 스크립트 업데이트 안내 팝업 및 건너뛰기 지원**, 그리고 **카테고리 드롭스(🎁) 실제 진행 여부 검증 및 보상 정보 표기 정상화**에 초점을 맞추었습니다.

## 🌟 개선/추가

### ⏱️ [OBS 연동 편의성]

#### 스크립트 업데이트 안내
- OBS 연동 스크립트의 새 버전이 출시되었을 때 무단으로 덮어쓰지 않고 독 화면에서 모달 팝업으로 정중히 안내
- 사용자가 원하는 경우 '현재 버전 다시 표시하지 않음'을 선택하여 불필요한 알림을 건너뛸 수 있도록 개선

## 🛠️ 수정

### 🛡️ [OBS 실행 안정성]

#### OBS 창 백그라운드 멈춤 해결
- OBS Studio 실행 시 프로그램 연동 과정에서 간헐적으로 OBS 화면이 뜨지 않고 백그라운드에 멈춰있던 결함 수정
- OBS 메인 화면과 장면 구성 요소 로딩이 100% 완료된 시점을 정확히 감지한 후 독 서버를 비동기로 안전하게 실행하도록 개선

### 🎁 [치지직 방송 제어]

#### 실제 진행 드롭스만 표시
- 치지직 카테고리 검색 시 이미 종료된 과거 이벤트 게임에도 드롭스(🎁) 아이콘이 잘못 노출되던 현상 수정
- 현재 내 채널에서 실제로 진행 가능한 실시간 활성 캠페인에만 🎁 아이콘이 정확하게 표시되도록 검증 강화

#### 드롭스 보상 목록 표기 정상화
- 드롭스 활성 카테고리 선택 시 툴팁에 보상 목록이 비어있거나 뜨지 않던 통신 경로 결함 수정
- 캠페인 상세 정보를 불필요한 우회 없이 직통으로 조회하여 시청 시간 조건 및 보상 아이템 정보가 정상 표기되도록 개선

### 🔒 [계정 및 보안]

#### 로그아웃 시 자식 창 종료
- 독 화면에서 로그아웃 시 실행 중이던 채팅창 및 리모컨 창이 백그라운드에 남지 않고 즉시 안전하게 닫히도록 개선
- 네이버 2차 인증 기기 기억 토큰은 안전하게 보존하여 다음 로그인 시 불필요하게 2차 인증을 반복하지 않도록 보호

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 안전 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공
