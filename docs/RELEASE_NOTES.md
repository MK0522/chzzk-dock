# Chzzk-Dock 0.6.4

# 네이버 로그인 창 종료·쿠키 잔류 긴급 패치

이번 업데이트는 **v0.6.3 정식 배포 직후 확인된 네이버 로그인 창 즉시 종료 및 이전 쿠키 잔류 문제를 해결하는 긴급 패치**입니다.

## 🌟 개선/추가

### ✨ [편의성]

#### 방송 카테고리 미지정 지원
- 방송 카테고리 선택 목록에서 `없음`을 골라 카테고리 없이도 방송 정보를 저장할 수 있도록 개선

## 🛠️ 수정

### 🔐 [로그인 안정성]

#### 로그인 창 1초 꺼짐 수정
- 네이버 로그인 창이 열린 직후 곧바로 닫히고 `로그인 미완료` 안내가 뜨던 현상 수정
- 로그인 창이 예기치 않게 종료되거나 대기 시간이 길어질 때 원인 파악이 쉽도록 진단 기록 보강

#### 이전 계정 쿠키 잔류 수정
- 로그인 창을 열 때 이전 계정 로그인 정보가 남아 자동 인식되던 현상을 예방하도록 시작·종료 정리 절차 개선
- 2차 인증 기기 기억 정보는 그대로 유지되어 매번 일회용 인증 번호를 다시 입력하지 않아도 되도록 보존

### ⚙️ [실행/안내]

#### 버전 표기·포트 안내 보완
- 일부 환경에서 프로그램 버전이 기본값으로 표시되던 문제 수정
- 기본 포트가 시스템 예약 포트와 겹칠 때 안내 창에 원인을 더 명확히 표시하도록 보완

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 유지
- 기존에 연동해 둔 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 창 크기 설정은 업데이트 후에도 그대로 유지됩니다.

#### 공식 설치형 인스톨러 제공
- 공식 설치형 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 배포되며, 검은 콘솔 창 없이 백그라운드 트레이로 실행됩니다.
