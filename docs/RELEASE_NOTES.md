# Chzzk-Dock 0.6.3 RC 2

# 인앱 자동 업데이트 무결성 검증 및 프로세스 정리 안정화

이번 업데이트는 **인앱 업데이트 다운로드 무결성 검증 및 자동 재시도**, **업데이트 실패 시 안전한 화면 복귀**, **구버전 잔여 파일 정리 신뢰성 향상**, 그리고 **개별 자식 창 종료 격리 안정화**에 초점을 맞추었습니다.

## 🌟 개선/추가

### 🔄 [자동 업데이트]

#### 다운로드 무결성 검증
- 업데이트 설치 파일 다운로드 시 파일 크기와 디지털 지문을 교차 검증하여 손상된 파일 실행 방지
- 일시적 네트워크 장애 발생 시 최대 2회까지 자동 재다운로드를 시도하여 설치 성공률 향상

#### 업데이트 실패 복구
- 다운로드 최종 실패 시 프로그램을 강제 종료하지 않고 안내 알림 표시
- 업데이트 모달을 닫고 원래의 업데이트 확인 화면으로 안전하게 복귀하여 언제든 재시도 가능

### ⏱️ [설치 및 유지관리]

#### 잔여 파일 정리 신뢰성
- 이전 버전의 임시 파일이나 구버전 바로가기 정리 실패 시 다음 실행에서 자동으로 재시도하도록 보강
- 실행 중인 화면 캐시 잠금으로 인한 비정상 무한 재시도를 예방하고 안전하게 최선 시도 처리

## 🛠️ 수정

### 🛡️ [프로세스 안정성]

#### 개별 창 닫기 격리
- 채팅창 또는 공식 리모컨 창의 [X] 버튼을 눌러 닫았을 때 다른 독 화면이 닫히거나 멈추지 않도록 격리
- 메인 독 서버가 비정상 종료되거나 꺼질 때는 열려 있는 자식 창들이 안전하게 함께 정리되도록 개선

#### 무인 설치 종료 동기화
- 인앱 무인 자동 업데이트 진행 시 프로그램에 정상 종료 신호를 먼저 전송하여 안전한 정리 후 설치 진행
- 신호 응답 대기 후 미종료 시에만 후속 조치를 취하는 2단계 안전장치 적용

## 📦 변경(패치)

### ⚙️ [시스템/배포]

#### 기존 설정 및 계정 보존
- 기존에 연동해 두신 네이버 로그인 정보, 다중 계정 목록, 방송 프리셋 및 화면 크기 설정은 업데이트 후에도 그대로 안전하게 보존됩니다.

#### 공식 인스톨러 패키지 제공
- 배포 파일은 공식 인스톨러(`chzzk-dock-setup.exe`) 단일 패키지로 제공
