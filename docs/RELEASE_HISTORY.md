# CHZZK OBS Dock - Release History

이 문서는 역대 배포 버전의 릴리즈 노트를 영구 보존하는 전용 아카이브입니다.

---

# v0.5.7 — 리소스 정합성 확보 및 인스톨러 잔여 캐시 정리
> 배포일: 2026-09-16

이번 업데이트는 구버전 리소스 잔재로 인한 UI 왜곡 방지 및 브라우저 캐시 무효화에 초점을 맞추었습니다.

## 🛠️ Fixes

### 바이너리 내장 HTML 강제 서빙
- 로컬 디스크 잔여 HTML 파일 우선 탐색 로직 완전 제거
- 실행 바이너리에 직접 임베딩된 정품 리소스만 100% 강제 서빙
- 작업 디렉토리 환경에 따른 구버전 UI 왜곡 원천 차단

### OBS 독 및 브라우저 캐시 무효화
- HTML 서빙 응답에 Cache-Control(no-store, no-cache, must-revalidate) 헤더 적용
- WebView2 및 OBS 브라우저 독의 로컬 디스크 캐싱으로 인한 화면 미갱신 방지

## 📦 Patches

### 인스톨러 구버전 잔여 파일 및 캐시 정리
- 구버전 인스톨러가 설치 폴더에 남겨둔 잔여 파일(chzzk-obs-dock.html, icon.ico) 강제 삭제 규칙 추가
- 독 팝업창 WebView2 디스크 캐시(EBWebView Cache) 자동 청소 탑재

### 릴리즈 파이프라인 UTF-8 인코딩 통일
- 배포 워크플로우 릴리즈 타이틀 인코딩을 UTF-8(No BOM)으로 규격화
- 배포 준비 스크립트 실행 환경을 최신 PowerShell(pwsh)로 일원화

# v0.5.6 — OBS 자동 종료 비활성화 옵션 지원 및 리모컨 UI 정돈
> 배포일: 2026-09-15

이번 업데이트는 방송 종료 후에도 독을 상시 유지할 수 있는 옵션 지원과 리모컨 화면의 직관적인 UI 정돈에 초점을 맞추었습니다.

## 🌟 Improvements

### 후원 피드 발생 시각 표기 개선
- 알림 발생 시점 기준 상대 시간(방금 전, N분 전 등) 실시간 표기
- API 패킷 데이터 필드별 타임스탬프 파싱 다중화 지원

### OBS 자동 종료 "사용 안 함" 옵션 추가
- OBS Studio 종료 후에도 독 서버 상시 구동 유지 지원
- 독 설정창 및 트레이 메뉴의 [OBS와 함께 종료]에 '사용 안 함' 선택지 탑재
- 프로세스 무기한 대기 로직 및 설정 파일(settings.json) 영속화

### 치지직 리모컨 테스터 인증 바이패스 연동
- 일반 사용자 대상 비활성화 안내 팝업 적용
- 인가된 테스터 전용 인증 코드 입력 및 영구 잠금 해제 지원

## 🛠️ Fixes

### 중간 광고 알림 식별 오류 수정
- 후원 피드에서 '(알 수 없음)'으로 잘못 분류되던 중간 광고 패킷 정상 식별
- 치지직 스튜디오 중간 광고 알림 타입 매핑 처리

### 컴퓨터 종료 시 트레이 잔상 수정
- Windows 정상 종료 및 재부팅 신호(WM_QUERYENDSESSION/WM_ENDSESSION) 감지 처리
- 트레이 아이콘(NIM_DELETE) 및 백엔드 리소스 선제 해제 후 안전 종료

## 📦 Patches

### 리모컨 간이 뷰 컨트롤러 및 링크 정리
- 비정상 동작하던 영상 10초 탐색(-10s, +10s) 및 이전/다음 버튼 완전 제거
- 간이 뷰 내부의 중복 공식 리모컨 바로가기 링크 삭제

### 배포 파이프라인 및 설정 유지
- 기존 로그인 쿠키 및 사용자 설정 파일 무중단 보존
- 공식 배포 에셋 2종 제공 (설치형 인스톨러 및 무설치 단일 실행 파일)

# v0.5.5 — 트레이 호버 툴팁 간소화, OBS 스크립트 업데이트 버튼 및 설정 아코디언
> 배포일: 2026-09-14

## 🌟 개선/추가

### ⏱️ [편의성]

#### OBS Lua 스크립트 버전 감지 및 원클릭 업데이트
- 설치된 스크립트 버전 불일치 시 독 설정창에 `[🔄 스크립트 업데이트]` 버튼 자동 노출
- 원클릭으로 OBS 스크립트 파일 즉시 최신화 지원

#### 자동 종료 시 Windows 알림 토글 옵션
- OBS 종료 및 미감지 자동 종료 시 Windows 알림 수신 여부 ON/OFF 토글 추가

## 🛠️ 수정

### 🛡️ [안정성]

#### 중복 실행 방지 및 기존 창 활성화
- 프로그램 다중 실행 시 신규 서버 기동 차단
- 기존 실행 중인 웹뷰 창 전면 포커스 복원

## 📦 변경(패치)

### 🎨 [UI/UX]

#### 시스템 트레이 호버 툴팁 간소화
- `ChzzkDock-v0.5.5, port:8081` 규격으로 가독성 일원화

#### 설정창 아코디언 그룹화
- 로그인 연동 설정 및 독 관리 제어 옵션 접이식 메뉴 적용으로 스크롤 피로도 개선

### ⚙️ [시스템/배포]

#### 사용자 설정 파일 분리
- 네이버 세션 쿠키는 Windows 보안 금고에 안전 보관
- 포트 및 일반 설정은 %LOCALAPPDATA% settings.json으로 격리 영속화
