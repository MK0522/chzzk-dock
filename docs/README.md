# <img src="icon.png" width="40" alt=""> CHZZK OBS Dock
OBS Studio 안에서 사용자 브라우저 독(`http://localhost:8081`)을 추가하면 CHZZK 방송 정보를 편하게 수정할 수 있습니다.

과거 트위치 시절처럼 스트리머들이 치지직 스튜디오에 접속할 필요를 줄여주는 것이 목적입니다.

## ✨ 주요 기능

- 📝 **원클릭 방송 설정** — 방송 제목(즉시 삭제 `✕`), 카테고리 실시간 검색, 태그 간편 추가/삭제
- 🎬 **치지직 같이보기 연동** — 목록에서 선택 시 규정(카테고리·클립·다시보기) 자동 고정 및 잠금
- ⚙️ **방송 옵션 & 다시보기** — 19금 연령 제한, 클립 허용, 다시보기(수동/자동/미생성) 자유로운 설정
- 💬 **채팅 권한 및 모드 제어** — 참여 대상(모두/팔로워/운영자)과 이모티콘 전용·저속 모드 즉시 반영
- ⭐ **후원 3종 원클릭 ON/OFF** — 방송 중에도 치즈·영상·미션 후원을 클릭 한 번으로 즉시 전환
- 🔗 **알림 URL & 스트림키 확인** — OBS 브라우저 소스 URL과 송출 스트림키를 한눈에 확인하고 복사
- 🔑 **안전한 네이버 간편 로그인** — 웹뷰 팝업으로 빠른 연동, Windows 암호화 금고로 계정 보호
- 🖥️ **윈도우 트레이 백그라운드** — 부팅 시 자동 실행 지원, 독 주소 복사 및 간편한 서버 제어

## 사용 방법

1. [Releases](../../releases)의 에셋에서 `chzzk-dock.exe`를 다운로드합니다.
> 버전명으로 인해 조금씩 다를 수 있습니다.
2. `chzzk-dock.exe`를 실행합니다.
3. OBS Studio에서 **보기 → 독 → 사용자 지정 브라우저 독**을 엽니다.
4. URL에 아래 주소를 입력합니다.
```text
http://localhost:8081
```
> 버전에 따라 주소는 변경 될 수 있습니다.
5. 열린 도크의 **⚙ 로그인 설정** 버튼에서 네이버 계정을 연동합니다.

이후 도크에서 방송 정보를 수정하고 **설정 저장**을 누르면 됩니다.

## 참고

- OBS 독에는 `http://localhost:8081` 주소를 등록하여 사용합니다.
- `쿠키 정보(NID_AUT, NID_SES)`는 평문 파일에 저장되지 않으며, Windows 자격 증명 관리자(암호화 금고)에 안전하게 보관되어 치지직 API 통신에만 사용됩니다.
- 서버를 종료하려면 작업 표시줄 알림 영역의 아이콘을 우클릭한 뒤 **서버 종료**를 선택합니다.
- Antigravity와 Codex를 활용해 개발되었습니다.

## 문제 해결

실행 시 “포트를 사용할 수 없습니다”라는 오류가 보이면, 이미 실행 중인 `8081` 해당 포트를 사용중인지 확인 후 다시 실행하세요.
