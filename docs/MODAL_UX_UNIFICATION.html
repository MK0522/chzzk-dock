OBS 브라우저 독 확인창 & 모달 UI/UX 통일화 기획안

브라우저 기본 window.confirm()을 독 내부의 세련된 다크 테마 커스텀 모달로 일체화하여 OBS 환경에서의 사용자 경험을 극대화합니다.

현재 상태: 브라우저 기본 confirm()의 한계
  • 다크 테마 붕괴: OBS 독은 올블랙 다크 모드인데, 흰색 투박한 Windows 기본 경고창이 팝업되어 눈부심 및 이질감 발생
  • Z-Order 먹통 위험: OBS Studio 내부 CEF(Chromium) 특성상 시스템 팝업이 간혹 OBS 창 뒤로 숨어 OBS 전체가 멈춘 것처럼 보임
  • 텍스트 제약: 줄바꿈 및 강조 스타일(위험 안내, 빨간색 버튼 등) 커스텀 불가
개선 방향: 독 일체형 다크 모달 (showConfirmModal)
  • 완벽한 테마 일체화: 독 내부 디자인과 100% 동일한 글래스모피즘 + 치지직 그린/경고 레드 스타일
  • 비동기 Promise 기반: const ok = await showConfirmModal({...}) 로 기존 코드 1줄 교체 가능
  • 안전성: ESC 키로 취소, 바깥 배경 클릭 닫기, 키보드 Enter 기본 포커스 지원

👀 실시간 시각적 비교 체험 (직접 눌러보세요)

BEFORE (현재 브라우저 기본 방식) window.confirm()

로그아웃이나 같이보기 퇴장 클릭 시 OBS 창 위에 브라우저 네이티브 다이얼로그가 뜹니다.

localhost:8081 내용:
치지직 연동을 해제(로그아웃)하시겠습니까? 저장된 쿠키가 삭제됩니다.
AFTER (개선된 일체형 다크 모달) showConfirmModal()

독 화면 전체에 은은한 딤드 배경이 깔리고 중앙에 직관적인 모달이 부드럽게 노출됩니다.
